# ল্যান্ডিং পেজ বট (Telegram)

দোকানদার বটে প্রোডাক্টের **ছবি + নাম + বিবরণ + দাম** পাঠালে বট নিজে থেকে একটা
**ল্যান্ডিং পেজ** (ওয়েবসাইটের পেজ, Chrome বা যেকোনো ব্রাউজারে খুলবে) বানিয়ে লিংক দেবে।
ক্রেতা সেই পেজ থেকে অর্ডার করলে অর্ডারের তথ্য সরাসরি **দোকানদারের WhatsApp-এ** চলে যাবে।
দোকানদারের WhatsApp নম্বর **শুধু একবার** দিতে হয় — বট তা সংরক্ষণ করে রাখে।

খরচ: **০ টাকা** — সব ফ্রি জিনিস ব্যবহার করা হয়েছে। পেজে কোনো অনলাইন পেমেন্ট নেই,
শুধু **ক্যাশ অন ডেলিভারি (COD)**।

## GitHub Actions দিয়ে চালানো (ফ্রি, সার্ভার লাগবে না) — আসল উপায়

বটটা GitHub Actions-এ **প্রতি ৫ মিনিটে একবার** চলে (ফ্রি — পাবলিক repo-তে Actions
মিনিট আনলিমিটেড)। কোনো নতুন অ্যাকাউন্ট লাগবে না, কার্ড লাগবে না, কম্পিউটার চালু
রাখতে হবে না।

**সেটআপ (একবারই):**

1. এই ফোল্ডারের ফাইলগুলো repo-তে পুশ করুন — repo-তে এইভাবে থাকবে:
   - `bot/bot.py`, `bot/landing_template.html`, `bot/requirements.txt`, `bot/README.md`
   - `.github/workflows/bot.yml`
   - `shop/` (বানানো পেজগুলো এখানে জমা হবে)
2. Repo-র **Settings → Secrets and variables → Actions → New repository secret**-এ যান:
   - Name: `BOT_TOKEN`
   - Secret: BotFather-এর token টি বসান → **Add secret**।
   - ⚠️ এই token কাউকে দেবেন না — শুধু এই Secret-এ বসাবেন, কোনো চ্যাটে পাঠাবেন না।
3. এরপর থেকে বট নিজে থেকে চলবে — প্রতি ৫ মিনিটে একবার Telegram চেক করে,
   নতুন মেসেজ থাকলে উত্তর দেয়, নতুন পেজ বানিয়ে repo-তে কমিট করে।

**পেজ কোথায় যাবে:** `https://mdirfanahmedrabbe-design.github.io/shop/<পেজের-নাম>.html`
— বট দোকানদারকে এই লিংকটাই দেবে।

**স্টেট কোথায় থাকে:** দোকানদারদের নম্বর, পেজের হিসাব, প্ল্যান (`owners.json`,
`products.json`, `plans.json`) আর কথোপকথনের অবস্থা Actions-এর **cache**-এ
(`bot-state`) সংরক্ষিত থাকে — প্রতি রানে আগের cache ফিরে আসে, তাই কিছু হারায় না।

**একটা সত্য কথা:** বট প্রতি ৫ মিনিটে একবার জেগে ওঠে, তাই প্রতিটি উত্তরের জন্য
সর্বোচ্চ ~৫ মিনিট অপেক্ষা করতে হতে পারে। একটা পেজ বানাতে কয়েক ধাপ লাগে, তাই
পুরো পেজ বানাতে একটু সময় লাগবে — কিন্তু টাকা লাগবে না, সার্ভারও লাগবে না।

হাতে চালাতে চাইলে: repo-র **Actions** ট্যাবে গিয়ে workflow-টি খুলে
**Run workflow** চাপুন।

`/activate` চালাতে চাইলে `OWNER_ID`-ও Secret হিসেবে বসাতে পারেন
(নাম `OWNER_ID`, মান আপনার Telegram user id)।

## ধাপ ১ — Telegram-এ বট বানান (BotFather)

1. Telegram অ্যাপে **@BotFather** খুঁজে খুলুন।
2. `/newbot` লিখে পাঠান।
3. বটের একটা নাম দিন (যেমন: `আমার দোকান বট`)।
4. তারপর একটা username দিন — শেষে `bot` থাকতে হবে (যেমন: `amardokan_bot`)।
   - username টি যদি নেওয়া থাকে, BotFather অন্য নাম দিতে বলবে।
5. BotFather একটা **token** দেবে (যেমন: `123456789:ABCdef...`)।
   - ⚠️ এই token **কাউকে দেবেন না, কোনো চ্যাটে পাঠাবেন না** — এটা বটের পাসওয়ার্ডের মতো।
   - token টা নিজের কাছে লিখে রাখুন।

## ধাপ ২ — .env ফাইলে token বসান

1. এই ফোল্ডারে `.env.example` ফাইলটি কপি করে নাম দিন `.env`।
2. `.env` ফাইল খুলে `BOT_TOKEN=` এর পরে আপনার token টি বসান:
   ```
   BOT_TOKEN=123456789:ABCdef...
   ```
3. প্রথমে পরীক্ষার জন্য `LINK_MODE=local` রাখুন (পেজ কম্পিউটারেই বানাবে, লিংক দেবে না)।
   আসল লিংকের জন্য নিচের ধাপ ৩ করুন।

> `.env` ফাইল শুধু নিজের কম্পিউটারে চালানোর জন্য। GitHub Actions-এ `.env`
> লাগে না — `BOT_TOKEN` Secret হিসেবে বসে, বাকি সেটিংস (`STATE_DIR`, `PAGES_DIR`,
> `PUBLIC_BASE_URL`, `LINK_MODE`) workflow ফাইলে থাকে। সেটিংগুলো পরিবেশ
> (environment) থেকেও নেওয়া যায় — `.env` না থাকলেও চলবে।

## ধাপ ৩ — GitHub Pages চালু করা (শুধু পুরনো `LINK_MODE=github` উপায়ের জন্য)

> 👉 এখন **GitHub Actions উপায়টাই** ব্যবহার হচ্ছে (উপরে দেখুন) — এই ধাপটি শুধু
> পুরনো github মোডে পেজ বানাতে চাইলে লাগবে, Actions উপায়ে লাগে না।

1. [github.com](https://github.com) এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন (না থাকলে)।
2. **New repository** বানান — নাম যেকোনো (যেমন: `landing-pages`), **Public** রাখুন।
   - Public রাখতেই হবে, নাহলে ফ্রি Pages-এ পেজ দেখা যাবে না।
3. Repo-র **Settings → Pages** এ যান:
   - **Source:** Deploy from a branch
   - **Branch:** `main`, ফোল্ডার `/ (root)` → **Save**।
4. **Token বানান:** GitHub-এ ডানদিকের ছবি → **Settings → Developer settings →
   Personal access tokens → Tokens (classic) → Generate new token**।
   - নাম দিন (যেমন: `landing-bot`)।
   - শুধু **`repo`** তে টিক দিন। **Generate token** চাপুন।
   - token টা একবারই দেখাবে — কপি করে রাখুন। **কাউকে দেবেন না।**
5. `.env` ফাইলে বসান:
   ```
   LINK_MODE=github
   GITHUB_TOKEN=আপনার_টোকেন
   GITHUB_REPO=আপনার-username/repo-নাম
   GITHUB_BRANCH=main
   PAGES_BASE_URL=https://আপনার-username.github.io/repo-নাম
   ```
   - `PAGES_BASE_URL` এ `username` আর `repo-নাম` আপনার নিজেরটা বসান।

## ধাপ ৪ — Python চালু করা

কম্পিউটারে Python 3.10 বা নতুন ভার্সন লাগবে।

```bash
cd telegram-landing-bot
pip install -r requirements.txt
python bot.py
```

চালু হলে দেখাবে: `Bot started (LINK_MODE=github)` — এরপর কম্পিউটার/সার্ভার বন্ধ করবেন না,
বট চালু থাকলেই কাজ করবে।

## ধাপ ৫ — বট ২৪ ঘণ্টা চালু রাখা (সবচেয়ে জরুরি কথা)

👉 **এখন আর নিচের কোনোটা লাগবে না — GitHub Actions উপায়টাই ব্যবহার হচ্ছে**
(উপরে দেখুন): বট প্রতি ৫ মিনিটে একবার নিজে থেকে চলে, কোনো সার্ভার লাগে না।

নিচের উপায়গুলো শুধু তখনই লাগবে, যদি বটকে সবসময় চালু (সাথে সাথে উত্তর দেওয়া)
রাখতে চান। Telegram বট কাজ করে শুধু যখন এটা চালু থাকে। নিজের কম্পিউটার বন্ধ
করলে বটও বন্ধ হয়ে যাবে। তাই বটটাকে সবসময় চালু রাখার একটা জায়গা লাগবে।

| **বাড়ির কম্পিউটার চালু রাখা** | কোনো সেটআপ নেই | বিদ্যুৎ/ইন্টারনেট গেলে বট বন্ধ। |

উপরের যেকোনো একটায় বট চলবে, তবে মাঝে মাঝে বন্ধ হলে আবার চালু করতে হবে।
এই বটের কোডে কোনো পেইড সার্ভিস নেই — টাকা খরচের কোনো ধাপ নেই।

- ফ্রি ৫টি শেষ হলে বা প্ল্যানের কোটা শেষ হলে বট আর পেজ বানাবে না — প্ল্যানের তালিকা দেখিয়ে পেমেন্ট করতে বলবে।

### দোকানদার কীভাবে প্ল্যান নেবে (আপগ্রেড)

1. দোকানদার bKash-এ প্ল্যানের টাকা পাঠাবে।
2. পেমেন্টের **TrxID** টি বটের মালিককে পাঠাবে (Telegram-এ)।
3. মালিক bKash অ্যাপে TrxID দিয়ে পেমেন্ট মিলিয়ে দেখবেন।
4. মিলে গেলে মালিক বটে এই কমান্ড চালাবেন:
   ```
   /activate <দোকানদারের Telegram user id> <300|600|1000>
   ```
   যেমন: `/activate 123456789 300`
   - দোকানদারের Telegram user id জানতে দোকানদারকে বলুন @userinfobot-এ `/start` দিতে।
   - প্ল্যান চালু হলে বট দোকানদারকে নিজে থেকে জানিয়ে দেবে।
5. প্ল্যান **চলতি মাসের জন্য** চালু হবে; পরের মাসে আবার পেমেন্ট করে নবায়ন করতে হবে।

> ⚠️ অটোমেটিক bKash যাচাই করা হয়নি — মার্চেন্ট অ্যাকাউন্ট ছাড়া এটা সম্ভব নয়।
> তাই পেমেন্ট মিলিয়ে দেখা আর `/activate` চালানো মালিকের হাতের কাজ।

### মালিকের সেটআপ

`.env` ফাইলে নিজের Telegram user id বসান — শুধু এই id-ই `/activate` চালাতে পারবে:
```
OWNER_ID=আপনার_Telegram_user_id
```
নিজের id জানতে Telegram-এ **@userinfobot** খুলে `/start` দিন।

## দোকানদার কীভাবে ব্যবহার করবে

1. Telegram-এ বটটি খুলে **/start** লিখুন।
2. বট WhatsApp নম্বর চাইবে — **একবারই** দিন (যেমন: `01712345678`)।
   বট নম্বরটি সংরক্ষণ করবে। পরিবর্তন করতে `/changenumber`।
3. এরপর বট **দোকানের নাম** চাইবে — **একবারই** দিন (যেমন: `রহিম স্টোর`)।
   এই নামটি আপনার প্রতিটি ল্যান্ডিং পেজে (উপরে ও নিচে) দেখা যাবে।
   দোকানের নাম না থাকলে `নেই` লিখুন। পরিবর্তন করতে `/myshop`।
4. নতুন প্রোডাক্টের জন্য **/newproduct** লিখুন (অথবা সরাসরি ছবি পাঠান)।
5. বট পরপর চাইবে:
   - **ছবি** — প্রথম ছবি পাঠান; আরও ছবি দিতে চাইলে পাঠাতে থাকুন
     (**সর্বোচ্চ ৪টি**), না চাইলে `শেষ` লিখুন।
   - **নাম** → **বিবরণ** → **দাম**
   - **আগের দাম** (অফার দাম, ঐচ্ছিক) — থাকলে লিখুন, না থাকলে `নেই` লিখুন।
     পেজে আগের দাম কেটে দেখাবে।
   - **স্টক** (ঐচ্ছিক) — কতটি আছে লিখুন, না থাকলে `নেই` লিখুন।
   - **ডেলিভারি চার্জ — ঢাকার ভিতরে** (ঐচ্ছিক) — সংখ্যা লিখুন, না থাকলে `নেই`।
   - **ডেলিভারি চার্জ — ঢাকার বাইরে** (ঐচ্ছিক) — সংখ্যা লিখুন, না থাকলে `নেই`।
6. সব ঠিক আছে কিনা দেখে **✅ নিশ্চিত করুন** চাপুন।
7. বট **ল্যান্ডিং পেজের লিংক** দেবে — সেই লিংক ক্রেতাদের পাঠান।
8. ক্রেতা লিংক খুলে (Chrome বা যেকোনো ব্রাউজার) নাম, ফোন, ঠিকানা ও পরিমাণ দিয়ে
   **"WhatsApp-এ অর্ডার করুন"** চাপলে অর্ডারটি আপনার WhatsApp-এ চলে যাবে।

অন্যান্য কমান্ড: `/myproducts` (বানানো পেজগুলোর লিংক), `/myplan` (প্ল্যান ও বাকি পেজ),
`/mynumber` (সংরক্ষিত নম্বর), `/myshop` (দোকানের নাম দেখুন/পরিবর্তন করুন),
`/help` (সাহায্য), `/cancel` (বাতিল)।

## ফাইলগুলো

| ফাইল | কাজ |
|---|---|
| `bot.py` | বটের মূল কোড (`python bot.py` — সবসময় চালু; `python bot.py --once` — একবার চালিয়ে বন্ধ, GitHub Actions-এর জন্য) |
| `landing_template.html` | ল্যান্ডিং পেজের নকশা (মোবাইল-প্রথম, বাংলা) |
| `requirements.txt` | লাগবে এমন Python লাইব্রেরি |
| `.env.example` | সেটিংসের নমুনা (`.env` বানিয়ে ব্যবহার করুন — শুধু লোকাল চালানোর জন্য) |
| `.gitignore` | গোপন ফাইলগুলো Git-এ যাবে না |
| `.github/workflows/bot.yml` | GitHub Actions workflow — প্রতি ৫ মিনিটে বট চালায়, নতুন পেজ কমিট করে |
| `shop/` | তৈরি হওয়া পেজ ও ছবি (Actions মোডে; `shop/README.md` দেখুন) |
| `owners.json` | দোকানদারদের সংরক্ষিত WhatsApp নম্বর (বট নিজে বানায় — `STATE_DIR`-এ থাকে) |
| `products.json` | বানানো পেজগুলোর রেকর্ড (বট নিজে বানায় — `STATE_DIR`-এ থাকে) |
| `plans.json` | প্রতিটি দোকানদারের প্ল্যান ও ব্যবহারের হিসাব (বট নিজে বানায় — `STATE_DIR`-এ থাকে) |
| `pages/` | তৈরি হওয়া পেজ ও ছবি (লোকাল মোডে) |

> পরিবেশ থেকে বদলানো যায়: `STATE_DIR` (স্টেট ফাইল কোথায় থাকবে),
> `PAGES_DIR` (পেজ কোথায় বানাবে), `PUBLIC_BASE_URL` (দোকানদারকে দেওয়া লিংকের
> শুরুটা), `BOT_TOKEN` / `OWNER_ID` / `LINK_MODE` / `GITHUB_*` — সবই
> `.env` ছাড়া শুধু environment variable দিয়েও চলবে।
